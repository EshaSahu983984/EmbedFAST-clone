# Group APIs

- Creates a new group under a specific tenant.
- Deletes an existing group under a specific tenant in the system.
- Executes a bulk operation to remove multiple users from a specified group.
- Performs a bulk operation to add multiple users to a designated group.
- Performs a bulk operation to assign access to multiple assets for a designated group.
- Performs a bulk operation to revoke access to multiple assets from a specified group.
- Retrieves a collection of user records associated with a specific group.
- Retrieves a list of assets associated with a specific group.
- Retrieves detailed information about a specific group belonging to a tenant.
- Retrieves groups associated with a specific tenant.
- Updates an existing group under a specific tenant in the system.
- Updates the access permissions for assets belonging to a specific group.
