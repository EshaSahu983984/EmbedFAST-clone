# Admin API documentation

The Admin APIs provide endpoints for administrative aspects of the solution, including branding, capacity, roles, tenants/workspaces, themes, groups, and users.&#x20;

It supports CRUD operations (Create, Read, Update, Delete) and additional functionalities, including:

* Starting/pausing capacities
* Refreshing semantic models
* Granular access control for users
* Logging trace information

The API uses Power BI REST APIs for a seamless integration, allowing for customization and configuration of capabilities for specific business needs.
