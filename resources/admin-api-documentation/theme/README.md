# Theme APIs

- Assigns a collection of themes to a specified tenant based on the provided tenant ID.
- Creates a new theme using the provided details as specified in the theme-related model schema.
- Deletes a specified existing theme using the provided theme ID from the system.
- Duplicates the specified theme with a new name provided by the user.
- Retrieves a comprehensive list of theme object models that are accessible within the context of a specified tenant.
- Retrieves details of a specific theme identified by its unique ID within the context of a specified tenant.
- Unassigns a list of themes from a specified tenant based on the provided tenant ID.
- Updates an existing theme using the provided theme-related model schema and theme ID.
