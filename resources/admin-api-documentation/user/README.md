# User APIs

- Assigns assets and a tenant to an existing user in the system.
- Creates a new user while simultaneously assigning specified assets.
- Deletes an existing user from the system.
- Deletes the dynamic dataset ID associated with a specific asset ID for a user.
- Retrieves a list of users based on optional parameters such as page number, page size, tenant ID, role ID, and asset ID.
- Retrieves details of the requested user based on the provided user ID.
- Revokes assets and tenant from an existing user based on provided asset details related to a specific tenant.
- Updates the dynamic dataset ID associated with a specific asset ID for a user.
