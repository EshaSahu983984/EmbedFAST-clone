# User API documentation

The User APIs provide endpoints for managing bookmarks, dashboards, datasets, reports, report subscriptions, themes, and user details.&#x20;

It supports CRUD operations (Create, Read, Update, Delete) and additional functionalities like generating embed tokens and exporting reports, using Power BI REST APIs for a seamless integration.
