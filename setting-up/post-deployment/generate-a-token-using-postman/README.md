# Generate a token using Postman

To interact with EmbedFAST APIs, you will need to generate an access token for authentication and authorization.&#x20;

Depending on your use case and integration requirements, EmbedFAST supports two types of tokens: [App + user token](app-+-user-token.md) and [App-only token](app-only-token.md). Each serves a different purpose in how authentication and authorization are handled.

The following sections will guide you on how to generate both types of tokens using Postman, along with the scenarios in which each should be used.
