# Version 2.0

{% hint style="info" %}
**Note:** Ensure you [**redeploy**](../redeploying-for-version-updates.md) EmbedFAST to receive these updates.
{% endhint %}



EmbedFAST v2.0 brings new features and optimizations for a better user experience:

* Performance and management processes are now streamlined.&#x20;
* Users can easily export data and access reports faster.&#x20;
* Sharing options are more customizable.
* The platform handles higher traffic efficiently.



## Key features in v2.0

1. **Export visuals into Excel**: Export Power BI visuals directly into Excel for easier data handling outside the platform.
2. **Favorite functionality**: Favorite up to 5 reports for quick access, saving time and improving workflow efficiency.
3. **Granular bookmark and report sharing**:
   * Users can now share bookmarks and reports with select individuals within their tenant.
   * Improves data privacy and relevance by enabling targeted sharing based on user needs.
4. **Database optimization for high traffic**:
   * Optimized database architecture to handle larger amounts of traffic, ensuring smooth performance even under heavy load.
   * Reduced the risk of operational blocks, improving overall system reliability and responsiveness.
5. **Improved the Admin page UI**:
   * Updated the Admin page UI to provide a more intuitive experience for tenant and user management.
   * Simplified navigation and task execution for administrators managing large user groups and tenant operations.



## Performance improvements

1. **Database tuning**: Optimized queries and infrastructure to improve performance under heavy traffic.
2. **Increased scalability**: Ensures that EmbedFAST can support a growing number of users and larger datasets without any degradation in performance.
